YES/NO MENUS:
- YES is always the TOP option, NO is the BOTTOM option.
- Press UP to select YES, DOWN to select NO, then A to confirm.
- Shortcut: B button always selects NO — use this to quickly decline.
- Default to YES for helpful actions (healing, accepting items, learning moves).
- Default to NO for risky actions (releasing Pokemon, overwriting saves) unless instructed otherwise.

MENU TIPS:
- A confirms, B cancels/exits. Arrow keys move cursor between options.
- ▶ or ▷ markers show the current cursor position.
- Keep pressing A through confirmation dialogs (select item → confirm quantity → done).
- Pokemon Yellow menus need 3-5 A presses to complete an action.
- ▼ (down arrow) at bottom-right of text = "press A to continue". Always press A.

NESTED MENU HANDLING (PC, shops, item storage):
Menus can be 3-4 levels deep. Track your depth:
1. Top menu (e.g. "WITHDRAW" / "DEPOSIT" / "TOSS" / "QUIT")
2. Item/Pokemon list
3. Quantity selector ("×1")
4. Confirmation ("Is that OK?")
Press A to go deeper. Press B to go back one level. B at the top level exits.
If you get lost, press B repeatedly until you see the top menu or the dialog closes.
